# **App Name**: MANGEMENT

## Core Features:

- Site Management: Enable administrators to add, edit, and delete construction sites with details like name, location, and status.
- Inventory Logging: Allow users to manually log materials and machines, tracking whether they are bought, used, or stored at each site.
- Expense Tracking: Implement a system for recording and categorizing expenses related to materials, labor, and transport for each site.
- Maintenance Logging: Create a maintenance logging system with schedules, alerts, and the ability to upload photos for damage or maintenance reports.
- Purchase Tracking: Track suppliers, costs, and quantities of purchases made for each site.
- Report Generation: Generate per-site summaries of inventory, expenses, and maintenance activities, and provide admins with access to hidden, role-specific logs.
- AI-Powered Maintenance Recommendations: Tool: Recommend which maintenance task types to log or prioritize given a brief textual summary of current site conditions, and other data in local storage.

## Style Guidelines:

- Primary color: A muted, authoritative blue (#4A6EBB) to evoke a sense of stability and trust.
- Background color: A light, desaturated blue (#E8F0FE) to create a clean, professional backdrop.
- Accent color: A contrasting yellow-orange (#FFB855) to highlight important actions and alerts.
- Body and headline font: 'Inter', a sans-serif with a modern, objective look suitable for both headlines and body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clear, recognizable icons from a standard library like Material Design Icons to represent different inventory items, expenses, and maintenance tasks.
- Employ a responsive, grid-based layout to ensure the application is accessible and usable across various devices (desktop and mobile).
